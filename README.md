# Hi, I'm Shlomo 👋

**שלום, אני שלמה** — בונה משחקים, אפליקציות ומערכות קוליות.

🎮 Founder of **[Shlomicom](https://shlomicom.com)**, an indie game studio. Our first game, **[TrollDoor](https://shlomicom.com/trolldoor)**, is a rage platformer out now on the App Store and Google Play.
